# Tabbed Navigation

> Download every version from the Tabbed Navigation page in your Gumroad library. See [Tabbed Navigation](https://design-with-cracka.gitbook.io/bricksmegamenupro/add-ons/tabbed-navigation) for how to use it.

## Version 1.3.2 - October 17, 2026

_Update from 1.3.1: replace the CSS and JavaScript of your **Tabbed navigation code** with the code from the 1.3.2 template. If you moved the JavaScript to a Code element or a code manager, replace it there._

### New

* **Open a tab from any link** on your site with Open in Menu. You need Mega Menu Pro 1.4.8.
* **`data-match-dropdown-width` attribute.** In a mega menu, a compact Tabbed Hero's menu item is as wide as the tab list. Set the attribute to `false` to keep the menu item's own width.

### Improved

* **Smoother heights.** The tab area no longer jumps the first time you open a menu, and a short tab no longer shrinks below the tab list.
* **Tabbed Navigation on a page** has the right height as soon as the page loads.
* **Compact Tabbed Hero in a mega menu.** The tab list keeps its height.

### Fixed

* **Mobile.** Tabs that open in place stay in one column.
* **Page transitions in Chrome and Edge.** Tabbed Navigation now restarts after the new page loads.
* **With the Sidebar Navigation Builder.** Both now load on the same page.
